Same 500 GB 2.5" SATA SSD (OS image) swapped between chassis for an apples-to-apples platform comparison · captured 2026-09-01/02

Open item — GPU driver on IQON-3 not confirmed. The old QXi-7000 Lite is confirmed running its AMD Radeon Vega 11 driver. The IQON-3's video driver could not be determined this round. Its integrated GPU is presumably the Radeon 760M bundled with the Ryzen 5 PRO 8640U, but that's inferred from the CPU model, not confirmed installed. This matters because the IQON-3's WinSAT Graphics subscore (7.3) came in lower than the old unit's (8.0) and is the sole bottleneck dragging its overall WinSPR score below the old machine's — the opposite of what the CPU/memory throughput numbers below would predict. Worth re-checking Device Manager for a generic/basic display adapter and re-running winsat formal once the proper driver is confirmed.

Data-quality notes
  • Both boot-times.csv files pull from the same OS install's event log (moved between chassis), so older rows overlap between the two folders — only the top row of each is trusted as unit-specific here.
  • WinSAT's per-effect Direct3D numbers (Batch/Alpha/ALU/Tex/Geometry/CBuffer) are fixed at 42.00 F/s on Windows 10/11 — a known platform quirk, not a real measurement — so the D3DScore (9.9/9.9) shouldn't be read as a real graphics differentiator.
